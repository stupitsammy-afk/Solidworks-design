# Solidworks-design
Designed a spur gear model and fan blade model using solidworks

# Spur Gear Design
Designed a spur gear model using SolidWorks to understand the basic geometry and working principles of mechanical power transmission. The model includes gear teeth, a central bore, and a circular gear profile. This project helped me practice 2D sketching, dimensions, extrude/cut features, and basic mechanical design.

# Fan blade design
Designed a multi-blade fan/propeller model using SolidWorks to explore the basic geometry of rotating components. The model consists of multiple curved blades arranged around a central hub. This project helped me practice creating repeated features, shaping curved components, and developing a basic understanding of blade geometry and rotational motion.
